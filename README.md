# 我的寵物美容工具箱

AI 資訊素養與應用（通識3）**期末成品範例**——課堂展示用。

一個整合式的一頁式工具網站，示範這門課期末作品該長什麼樣子：
一個首頁 + 三個工具頁，全部由 AI 協助產出，放在 GitHub Pages 上。

| 頁面 | 內容 |
|---|---|
| `index.html` | 首頁：工具導覽 |
| `price.html` | 洗澡美容價格試算器（多欄位輸入 + 條件判斷） |
| `age.html` | 寵物年齡換算器（犬貓公式不同） |
| `food.html` | 犬貓危險食物查詢（搜尋 + 三重篩選） |

> ⚠️ 本站為教學示範用途，價格與資料皆為虛構範例，不構成專業建議。
